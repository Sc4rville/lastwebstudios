# Design — the engine's library (catalogue)

`design/` is the **catalogue** the free composer draws from. A **library-first** model (details:
`docs/DESIGN-ENGINE.md`): we **extract** assets from real sites (`extractize`), **sort them here**,
then **compose** a bespoke site from this catalogue (`composer`).

## The catalogue
| folder | contents | fed by |
|---|---|---|
| `fonts/` | self-hosted families (woff2) + `index.json` (registry) | `extractize`, `harvest:fonts` |
| `palettes/` | `<slug>.json`: colour CSS variables + dominant colours | `extractize` |
| `motion/` | `<slug>.json`: the animation/scroll stack detected + its mechanism | `extractize` |
| `sections/` | sanitised section skeletons from award-winning sites + `index.json` | `extractize` |
| `industries/` | one `playbook.md` per trade (structure, angle, mood) + `RADAR.md` (generated by `npm run radar`) | by hand, `radar-industries` |
| `catalog.json` | the **master catalogue**: one entry per site (fonts, palette, motion) | `extractize` |
| `composer/` | the free composer (mantras + scratch of the runs) | skill `composer` |
| `templates/` | **complete** templates of a domain (secondary route) | `templatize` |
| `scripts/` | mechanics: `fill`, `polish`, `animate`, `lint`, `asset-audit`, `demo-video`, `harvest-fonts`, `extractize` | — |
| `verify/` | the deterministic visual net (`verify.cjs`: overflow, broken images, voids) | — |

## Flow
```
extractize <url> → fonts/ palettes/ motion/ sections/ catalog.json   (EXTRACT)
composer <prospectId> → output/sites/<id>/<date-composer>/            (COMPOSE, draws from the catalogue)
```

`.extract-cache/` (extractize's render cache) is **thrown away** after each extraction and gitignored.
The playbooks are written in English; the composer writes each site in the agency's language.
