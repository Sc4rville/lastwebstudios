# Sample data (fictional casts)

LWS's **fictional casts**: what `npm run sandbox` loads to show an agency at work, with no key, no account and not a
single piece of real data. Everything is invented. There are two demo studios:

- **The US studio (the default, `npm run sandbox`)**: "Harbor & Pine Web Co." in Austin
  (`agency.config.example.us.json`), six invented Austin businesses (two pool builders, a plumber, a roofer, a carpenter, a
  kitchen maker), one at every stage of the funnel, reserved `.example` domains (RFC 2606), NANP
  555-01xx fiction numbers, Austin ZIP codes, English sites. `cast.us.json` + `us/`.
- **The French studio (`npm run sandbox -- --country FR`)**: "Atelier Vélin" (`agency.config.example.json`), 8 prospects
  on 3 trades (pool builder, joiner, kitchen maker), invented towns, `.example` domains, phone numbers in the ARCEP
  ranges reserved for fiction (`01 99 00`, `02 61 91`, `03 53 01`, `04 65 71`, `05 36 49`, `06 39 98`), SVG illustrations
  made from scratch. `cast.json` + `sites/`, `data/`. Its sites, emails and notes are in French on purpose: it is the
  French agency's own language.

| what | where | where it comes from |
|---|---|---|
| the cast and its story (who is at which stage) | `cast.json`, `cast.us.json` | written by hand |
| the dated old sites (2009, 2011, 2013) | `sites/<prospect>/`, `us/sites/<prospect>/` (+ `test/fixtures/sites/orvane-piscines/`) | made from scratch |
| the gate's scores | `data/raw/<id>.score.json` | **real outputs** of `score.ts` on the old sites (VISUAL=0, no SIREN), or fictional |
| "before" screenshots, logos, photos | `data/assets/<id>/` | **real outputs** of `parse.ts` (Playwright) on the old sites |
| the `ProspectSheet` fiches | `data/prospects/<id>.json`, `us/data/prospects/` | real runs (Orvane, Brisane) or written by hand |
| the scraper's pool | `data/raw/prospects.scraped.csv` | fictional, same format as the real one |
| the sequencer's emails | `data/savior/`, `data/demo/` (and under `us/data/`) | fictional (the real ones are generated by `npm run savior`) |
| the built sites | `examples/<prospect>/site/` | **real runs** of `npm run first-site` (Claude plan, blind judge PASS); the US cast's built sites are demo stand-ins the sandbox renders from their own facts |

The sandbox copies these files into a throwaway folder (`.sandbox/`), never into `data/`: your repository stays empty of
prospects. To regenerate the scores and screenshots: serve `sites/<x>/` locally, then
`npm run score -- <id> <url> <trade>` and `parsePage()` (see `test/fixtures/README.md`).
